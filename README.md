# Smart Study Planner (Groq AI helper)

1. Get a free key at https://console.groq.com (API Keys > Create API Key).
2. Double-click start.bat. On first run it creates .env and opens it.
3. Paste the key after GROQ_KEY= (one line, no spaces), save, close Notepad.
4. The site opens at http://localhost:3000. Keep the black window open.
